# 🎮 Pokédex

Projeto acadêmico de desenvolvimento front-end que consiste em uma Pokédex integrada à PokéAPI, permitindo explorar diferentes Pokémon e suas características.

## 🚀 Funcionalidades
- Listagem dinâmica de Pokémon.
- Pesquisa de Pokémon pelo nome.
- Filtro por tipo.
- Visualização de detalhes em uma janela modal.
- Exibição de imagem, número, tipos, altura e peso.
- Layout responsivo para diferentes dispositivos.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- PokéAPI

## 🌐 API utilizada

[PokéAPI](https://pokeapi.co/)

## 🎯 Objetivo do projeto

Praticar o consumo de APIs utilizando JavaScript, a manipulação do DOM e a criação dinâmica de elementos HTML, desenvolvendo uma aplicação interativa e responsiva.

---

Desenvolvido como projeto acadêmico da disciplina de Desenvolvimento Front-End.
